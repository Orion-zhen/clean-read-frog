# WebDAV 配置同步

在「偏好设置 → 配置 → WebDAV 云同步」中配置连接，然后手动同步。

1. 在服务器上创建一个专用目录，例如 `read-frog`。
2. 填写该目录的 WebDAV URL、用户名和密码或应用专用密码。
   例如 `https://example.com/remote.php/dav/files/alice/read-frog/`。
   这里需要 WebDAV 接口地址，不是网盘分享链接。
3. 可先点击「测试连接」。这只验证目录可读取，不会创建测试文件，也不验证写入权限。
4. 保存连接，点击「同步到 WebDAV」。首次同步会要求确认：远端已有配置时覆盖本地，否则上传本地配置。

远端文件固定为 `read-frog-config.json`，采用与 Google Drive 相同的
`{ value, meta: { schemaVersion, lastModifiedAt } }` 格式。后续同步复用现有的同步方向判断、配置迁移和字段冲突选择界面。

## 范围与限制

- 支持一个连接、手动同步和 HTTP Basic 认证。不创建目录，不自动重试。
- 文件读写使用 GET / PUT。连接测试和首次创建文件前的目录检查使用 Depth 0 PROPFIND。
- 必须填写最终接口地址。请求不会跟随重定向，也不会绕过证书验证。
- 单次请求超时为 30 秒，读取响应最多 10 MiB。
- 服务器提供强 ETag 时，更新使用 `If-Match`。新建文件使用 `If-None-Match: *`。
  HTTP 412 表示远端已变化，需要重新同步。服务器没有强 ETag 或不遵守条件请求时，无法保证并发写入安全，请避免多台设备同时同步。
- 合并配置沿用共享引擎的写入顺序：先保存本地，再上传。上传失败时不会更新同步基线，但已保存的本地合并结果会保留。

## 存储与安全

连接凭据只保存在扩展的 `local:webdavSettings` 中，不加入主配置，因此不会被配置导出或同步到 Google Drive / WebDAV。
本地存储未加密。同步的主配置可能包含翻译服务的 API 密钥，建议使用 HTTPS、专用目录和应用专用密码。
HTTP 会以未加密方式传输凭据和配置。

WebDAV 使用独立的 `local:webdavSyncBaseline` 保存最近一次同步基线。
目标身份由规范化后的文件 URL 和用户名组成，不包含密码。
切换目标时不使用其他目标的基线，更换密码不会改变目标身份。
清除连接会删除本地凭据和 WebDAV 同步记录，不会删除远端文件、本地配置或 Google Drive 同步记录。

## 维护

WebDAV 实现集中在此目录及设置页的 `webdav-sync/` 中。
共享同步引擎和 Google Drive 适配器不包含 WebDAV 分支。
新增文案提供英语、简体中文和繁体中文，其他界面语言使用项目已有的英语回退。
